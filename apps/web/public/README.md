# Public assets

Place the product logo here as **`logo.png`** (the LogiQ Estates Pro lockup).
It is shown on the login / register screens via `components/brand-logo.tsx`.

- Recommended: a transparent PNG, roughly 600–1000px wide, height ~200px.
- Until `logo.png` exists, the auth screens fall back to the text wordmark.

Optional: add `favicon.ico` here to set the browser tab icon.
